## FAQ

### What is XCutors?

XCutors is a curated Windows desktop collection that bundles multiple popular Roblox executors and a universal script loader into one unified interface for convenience and ease of use.

### Which executors are included?

XCutors ships with Volt, Synapse Z, Potassium, Wave, and the xcutorsLoader universal loader. All are maintained and updated regularly.

### Is XCutors free to use?

XCutors itself is free and open-source. Some individual executors bundled within may require their own licenses or subscriptions—check each executor's page for details.

### Does XCutors work on Mac or Linux?

Currently, XCutors is Windows-only. We are evaluating potential cross-platform support in future releases, but no timeline has been announced.

### How do I update the executors?

XCutors includes an auto-updater. Simply open the application, navigate to Settings > Updates, and click 'Check for Updates.' All bundled executors will be updated simultaneously.

### Is my account safe when using XCutors?

We recommend using an alternate or test account when experimenting with scripts. While XCutors is designed to be stable, running third-party scripts always carries inherent risks.

### Can I add my own scripts to the library?

Yes. Navigate to the Script Library tab, click 'Add Script,' and paste your Lua code. You can organize scripts into folders and tag them for quick access.

### Where can I report bugs or request features?

Please open an Issue on our GitHub repository using the provided templates. For feature requests, use the 'Feature Request' template so we can triage and prioritize accordingly.

### Does XCutors collect any data?

XCutors does not collect personal data. Anonymous usage statistics may be gathered to improve stability, and this can be disabled entirely in Settings > Privacy.
